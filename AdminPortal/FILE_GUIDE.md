# Angular File Guide

Source files contain learning headers. These format/tool-owned files are documented here instead:

- `package.json`: valid JSON manifest containing Angular dependencies and npm scripts.
- `package-lock.json`: generated exact dependency versions; do not edit manually.
- `angular.json`: Angular CLI workspace, build, and dev-server configuration.
- `src/app/features/customers/customer-api.service.ts`: customer HTTP adapter.
- `src/app/features/products/product-api.service.ts`: product HTTP adapter.
- `src/app/features/orders/order-api.service.ts`: order HTTP adapter.
- `src/app/shared/models.ts`: shared TypeScript API response contracts.
- `tsconfig*.json`: TypeScript compiler configuration.
- `index.html`: the browser host page for Angular.
- `.vscode/`: editor convenience settings generated by Angular CLI.
- `public/`: static browser assets.
- `node_modules/`, `.angular/`, and `dist/`: generated/dependency output; do not edit or annotate file-by-file.
